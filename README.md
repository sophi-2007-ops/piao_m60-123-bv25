* 1. Описание структуры проекта
'src/' - корневой пакет исходного кода приложения
'db/' - подпакет, содержащий логику приложения и интерфейс
'__init__.py' - маркер инициаизации подпакета
'__main__.py' - точка входа в приложение, инициализирующая запуск основного циклатекстового интерфейса
'tui.py' - модуль текстового пользовательского интерфейса
'backend/' - подпакет, реализующий внутреннюю логику базы данных
'__init__.py' - маркер инициализации подпакета бэкенда
'memory.py' -  реализация in-memory базы данных
'database.py' - абстрактный базовый класс для всех форматов БД
'errors.py' - файл с основнымм ошибками
'file_csv' - реализация базы данных, сохраняющей данные в формате csv
'file_json' - реализация базы данных, сохранябщей данные в формате json
'table' - модуль таблицы с валидацией даных
'tests/' - пакет с тестами приложения
'__init__.py' - маркер инициализации пакета тестов
'test_memory.py' - модуль с тестами для in-memory бэкенда
'test_tui.py' - модуль с тестами для интерфейса
'test_file_database' - модуль с тестами для файловых бэкендов

* 2. Описание реализованной функциональности
В рамках выполнения работы были полностью реализованы требования основных и части дополнительных задач:
- Универсалная архитектура БД. Абстрактный класс Database позволяет добавлять новые форматы хранения
- Три формата хранения: in-memory, JSON, CSV
- Реализация структуры хранлища через класс Table с фиксированным набором колонок
- Добавление записей с валидацией данных
- Поиск по фильтрам по одному или нескольким полям
- Обновление записи по ID
- Удаление записи и очистка всей таблицы
- Валидация данных: формат телефона, возраст, дубликаты ID
- Реализован консольный интерфейс с выбором формата БД при запуске
- Сохранение данных между сессиями для файловых форматов
- Оформление по PEP8
- Реализованы тесты с общим покрытием 91%

* 3. Инструкция по запуску проекта
1) Пожалуйста, откройте терминал в корневой директории проекта
2) Выполните команду "py -m src.db" для запуска пакета как модуля
3) Выролните команду "py -m pytest --cov=src --cov-report=term-missing" для запуска тестов
