* 1. Описание структуры проекта
'src/' - корневой пакет исходного кода приложения
'db/' - подпакет, содержащий логику приложения и интерфейс
'__init__.py' - маркер инициаизации подпакета
'__main__.py' - точка входа в приложение, инициализирующая запуск основного циклатекстового интерфейса
'tui.py' - модуль текстового пользовательского интерфейса
'backend/' - подпакет, реализующий внутреннюю логику базы данных
'__init__.py' - маркер инициализации подпакета бэкенда
'memory.py' -  ядро базы данных, содержащее объявление глобального хранилища базы данных

* 2. Описание реализованной функциональности
В рамках выполнения работы были полностью реализованы требования основных и дополнительных задач:
- Реализация структуры хранилища. Данные хранятся в оперативной памяти в виде таблицы People 
- Добавление записей. Реализовано добавление данных с предварительно проверкой существования целевой таблицы
- Поиск по фильтру. Поддерживается поиск записи по одному или нескольким пунктам
- Обработка ошибок и валидация данных
- Реализован простой консольный интерфейс с текстовым меню, позволяющим взаимодействовать пользователю с базой данных
- Удаление записей. Реализованы функции, позволяющие удалить либо одну запись, либо очистить всю таблицу
- Обновление по фильтру. Возможность точечно изменять отдельный пункты записи
- Оформление по PEP8

* 3. Инструкция по запуску проекта
1) Пожалуйста, откройте терминал в корневой директории проекта
2) Выполните команду "py -m src.db" для запуска пакета как модуля
